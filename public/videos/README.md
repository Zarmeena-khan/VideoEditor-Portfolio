# Video Files Placeholder

Add your project video files here with the following naming convention:

- `project-1.mp4`
- `project-2.mp4`
- `project-3.mp4`
- ... up to `project-10.mp4`

These videos will appear in the infinite scrolling reel on the Work section.

**Recommended specs:**
- Format: MP4 (H.264)
- Resolution: 1080x1800 (portrait 9:16)
- Duration: 15-30 seconds
- File size: < 10MB each
